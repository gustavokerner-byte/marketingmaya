## Para trocar alguma imagem

Suba o arquivo novo aqui **com o mesmo nome** da tabela (Add file → Upload files
no GitHub). A página troca sozinha, sem mexer no código. Formatos: JPG ou PNG,
deitadas, até ~400 KB depois de otimizadas.

**Vídeo:** reportagem do SBT Brasil (`8PKEs2xY0jI`), configurada em `YOUTUBE_ID`.
